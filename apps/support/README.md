# Phase 10 — Customer Support

EnterpriseOne's support module provides multi-tenant ticket management, agent/team assignment, SLA tracking, conversation history, status history, satisfaction surveys, knowledge-base articles, canned responses, escalation rules and reporting.

## Main workflows
1. Create a ticket and optionally associate a CRM account.
2. Apply category, priority and SLA policy.
3. Assign a team/agent.
4. Exchange customer-facing or internal messages.
5. Track first response and resolution deadlines.
6. Resolve/close or reopen tickets while preserving history.
7. Collect customer satisfaction.
8. Publish searchable knowledge articles.

## Routes
- `/support/` dashboard
- `/support/tickets/` ticket queue
- `/support/tickets/create/` ticket creation
- `/support/knowledge/` knowledge base
