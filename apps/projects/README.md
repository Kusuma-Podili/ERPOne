# Phase 9 — Project Management

EnterpriseOne Phase 9 adds project portfolio management on top of the existing organization, CRM, finance and HR modules.

## Capabilities
- Project lifecycle, priorities, budgets, dates and client linkage.
- Project membership, roles, allocation and rates.
- Milestones and owners.
- Tasks, subtasks, assignments, priorities, status, dates and estimates.
- Task dependencies, comments and checklists.
- Timesheets and billable work.
- Project expenses and budget lines.
- Status history and activity audit trail.
- Portfolio dashboard and workload/reporting services.

## Integration points
Projects are tenant-scoped through `organizations.Organization`, can reference CRM accounts, and expose financial measures for the Finance and Analytics phases.
