# Phase 11 - Analytics & Reporting

EnterpriseOne analytics provides reusable metrics, KPIs, dashboards, widgets, report definitions, scheduled-report configuration, snapshots, alerts, domain summaries, audit events, report execution history, and export support.

The engine intentionally separates metric calculation primitives from domain adapters so CRM, sales, inventory, finance, HR, payroll, projects, and support can contribute specialized analytics without duplicating dashboard/report infrastructure.
